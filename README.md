# Mijn roze terminal

Een persoonlijke Nederlandstalige blog, gebouwd met [Hugo](https://gohugo.io/) en het [Terminal-thema](https://github.com/panr/hugo-theme-terminal).

## Lokaal bekijken

```bash
git submodule update --init --recursive
hugo server -D
```

Open vervolgens de lokale URL die Hugo toont. Maak een productieversie met `hugo --gc --minify`.

Na configuratie wordt de site via GitHub Actions gepubliceerd op GitHub Pages. Zie de lokale `HANDLEIDING.md` voor persoonlijk beheer; die staat bewust niet in deze repository.
